Renders a Lucide glyph — the only icon system in StudySession Pro; use it wherever the product shows an icon.

```jsx
<Icon name="code-2" size={24} color="var(--color-primary)" />
```

Requires the lucide UMD script on the page. Common names in the app: code-2 (brand mark), home, library, bar-chart-3, settings, git-branch, scroll-text, search, chevron-right, x, play, flame, target, trophy, cloud, hard-drive, graduation-cap, lightbulb, download, upload, trash-2.
